# Operations

Contains the dedicated [development tunnel ingress](cloudflared.dev.yml), [connector user service](smartcindy-dev-tunnel.service), and reviewed Danny systemd unit definitions for the development API, PostgreSQL, and Inspiron SSH origin relay. The units are installed/active on their respective hosts; see [runtime operator guide](../docs/operations/danny-development-api.md) and [tunnel lifecycle](../docs/operations/development-tunnel.md). The older local API unit `smartcindy-dev-api.service` is superseded and is not an active runtime path. Production Caddy, deployment, and backup configuration are not implemented. Checks and deployment are manual and reviewed; no GitHub Actions. Keep credentials outside the repository. See [architecture](../docs/architecture.md) and [Danny build operations](../docs/operations/danny-build.md).
